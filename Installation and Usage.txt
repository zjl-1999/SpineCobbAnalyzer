================================================================
 Spine COBB Analyzer  安装与运行说明（源代码版）
 —— 写给第一次拿到这份文件的人，照做即可，不需要懂编程
================================================================

这是一个用 Python 写的脊柱 COBB 角分析软件，带图形界面。
你拿到的是【源代码】，需要在自己电脑上装好运行环境才能打开。
照下面步骤一步步做即可。全程约 15-20 分钟，主要在等下载。

适用系统：Windows / macOS / Linux 均可（本说明以 Windows 为主，
          Mac/Linux 用户见文末“其他系统”一节）。


================================================================
 第一步：安装 Python（运行这个软件的“发动机”）
================================================================

1. 浏览器打开：https://www.python.org/downloads/

2. 下载 3.10 或 3.11 版本（★不要用最新的 3.13，部分库未必适配）。
   若首页按钮是最新版，往下找 “Looking for a specific release”，
   选 3.11.x 下载。

3. 双击安装包。
   ★★★ 最关键的一步 ★★★
   安装界面最下方有个勾选框：
       [ ] Add Python to PATH
   ☑ 必须先打勾，再点 “Install Now”。
   （不勾的话后面命令全用不了，这是新手最常见的错误）

   另外建议：勾选界面里若有 “tcl/tk and IDLE”，保持勾选状态
   （本软件界面依赖 tkinter，正常安装包都自带，无需额外操作）。

4. 装完点 “Close”。


================================================================
 第二步：检查 Python 是否装好
================================================================

1. 按 Win 键，输入 cmd，回车，打开黑色“命令提示符”窗口。

2. 输入下面这行后回车：
       python --version

3. 显示 “Python 3.11.x” 之类 → 成功。
   提示“不是内部或外部命令” → 第一步没勾 PATH，请卸载重装并勾选。

4. 顺便确认界面库（tkinter）正常，输入：
       python -m tkinter
   如果弹出一个小窗口，说明界面库正常，关掉它即可。
   （极少数精简版 Python 会缺它，弹不出来就需要重装官方版 Python）


================================================================
 第三步：安装软件需要的扩展库（一次性）
================================================================

方法一（★推荐，一行搞定，版本自动匹配★）：
   1. 在命令窗口中，用 cd 命令进入本软件所在文件夹，例如：
          cd “D:\下载\SpineCobbAnalyzer”
      （路径改成你实际解压的位置，有空格要加引号）

   2. 执行下面这行：
          pip install -r requirements.txt

      【国内下载慢】改用清华镜像：
          pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

   等几分钟，光标恢复可输入、没有红色 ERROR → 成功。

方法二（不会 cd 命令的话，用这个手动装）：
   在命令窗口里粘贴下面一整行后回车（窗口里点右键即可粘贴）：

   pip install opencv-python==4.10.0.84 numpy==2.2.6 scipy==1.16.3 matplotlib==3.9.2 pillow==12.2.0 pandas==2.3.3 openpyxl==3.1.5 python-docx==1.2.0

   【国内下载慢或失败】在上面整行末尾加上清华镜像参数：

   pip install opencv-python==4.10.0.84 numpy==2.2.6 scipy==1.16.3 matplotlib==3.9.2 pillow==12.2.0 pandas==2.3.3 openpyxl==3.1.5 python-docx==1.2.0 -i https://pypi.tuna.tsinghua.edu.cn/simple

说明：界面库 tkinter、数据库 sqlite3 等是 Python 自带的，无需安装。

★ 为什么要指定版本号？
   这些是开发者实际使用的版本，能保证兼容性。如果你装了更新的版本遇到
   报错，可以用上面带版本号的命令重装回指定版本。


================================================================
 第四步：运行软件
================================================================

方法 A（推荐给电脑小白）：
   1. 打开收到的 SpineCobbAnalyzer 文件夹。
   2. 在文件夹空白处，按住 Shift + 鼠标右键。
   3. 选“在终端中打开”或“在此处打开 PowerShell 窗口”。
   4. 输入下面这行后回车：
          python Spine_COBB_Analyzer.py
   5. 等几秒，软件界面弹出。

方法 B（装了 VSCode 的话）：
   用 VSCode 打开本文件夹 → 打开 Spine_COBB_Analyzer.py
   → 点右上角“运行”三角按钮。
   （首次运行 VSCode 可能提示选择 Python 解释器，选你刚装的那个即可）


================================================================
 ★ 重要：必须和本程序放在同一文件夹里的文件 ★
================================================================

本软件启动时会读取同目录下的这几个文件，缺一不可：
   - Spine_COBB_Analyzer.py   （主程序）
   - config.py                （启动配置，缺了直接报错打不开）
   - config.json              （配置数据，程序要读）

所以运行时，请保证上面三个文件在同一个文件夹里，不要单独只拷主程序。
data 文件夹（测试图片/表格）是示例数据，放一起即可。


================================================================
 关于显示字体（影响图表里的中文是否正常）
================================================================

软件作图时会优先使用系统的“宋体(SimSun)”和“Times New Roman”。
   - Windows：系统自带，一般不用管。
   - Mac/Linux：若图表中文显示成方块/缺字，需自行安装中文字体
     （如思源宋体 Noto Serif CJK），装好重启软件即可。
   - 即使缺字体，软件也不会崩溃，只是中文可能显示异常。


================================================================
 关于 AI 功能（可选，不用也能正常使用全部分析功能）
================================================================

本软件带一个【可选】的 AI 辅助功能，不用它完全不影响其它功能。

如果要用 AI：
   1. 记事本打开本文件夹里的 .env 文件。
   2. 选一个服务商，去掉对应行前面的 # 并填上自己的密钥，例如硅基流动
      （国内申请方便、有免费额度）：
          SILICONFLOW_API_KEY=sk-你自己的真实密钥
      申请地址：https://cloud.siliconflow.cn/
   3. 保存即可。
   4. 国内用户若用 Gemini/Claude/OpenAI，可能需要科学上网，并在软件
      AI 设置里填代理地址（如 http://127.0.0.1:7890）。
   （密钥是私人的，切勿外传或上传网络）


================================================================
 常见报错与解决（别人最可能遇到的）
================================================================

【现象】双击 .py 文件一闪而过 / 没反应
  → 不要双击。必须按“第四步”用命令方式运行。

【报错】ModuleNotFoundError: No module named 'cv2'
  → 缺 OpenCV。执行：  pip install opencv-python

【报错】No module named 'scipy' / 'matplotlib' / 'PIL' / 'pandas'
        / 'openpyxl' / 'docx'
  → 对应缺库，分别执行（注意 PIL 对应 pillow，docx 对应 python-docx）：
        pip install scipy
        pip install matplotlib
        pip install pillow
        pip install pandas
        pip install openpyxl
        pip install python-docx
     省事做法：把第三步那一整行重新跑一遍即可全部补齐。

【报错】No module named 'config'
  → 说明 config.py 没和主程序放在同一文件夹。把 config.py、config.json
     和主程序放到一起再运行。

【报错】No module named 'tkinter' / 'ModuleNotFoundError: _tkinter'
  → 你的 Python 缺界面库。重装官方版 Python（python.org），
     安装时确保带 tcl/tk（官方安装包默认就带）。

【报错】pip 不是内部或外部命令
  → Python 没装好或没勾 PATH。回第一步重装并勾选 Add Python to PATH。

【现象】界面文字/图表是方块或乱码
  → 缺中文字体，见上文“关于显示字体”一节。

【现象】导出 Word 报告失败
  → 缺 python-docx，执行：  pip install python-docx


================================================================
 其他系统（macOS / Linux）
================================================================

- 安装 Python 3.10/3.11（Mac 可用 python.org 安装包或 Homebrew；
  Linux 用系统包管理器，并确保安装了 python3-tk）。
  例如 Ubuntu：  sudo apt install python3 python3-tk python3-pip
- 安装库的命令同上（Mac/Linux 通常用 pip3 代替 pip，python3 代替 python）：
      pip3 install opencv-python numpy scipy matplotlib pillow pandas openpyxl python-docx
- 运行：  python3 Spine_COBB_Analyzer.py
